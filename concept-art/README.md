# Concept art

Reference images for the mod's 3D models: one subfolder per object (for example `small-tub/`), holding the front, left, right and rear
views as separate files (`front.png`, `left.png`, `right.png`, `rear.png`). The prompts are in
[art-prompts.csv](../docs/art-prompts.csv).

This folder is never packaged: release zips hold only the built `Bathhouse` mod folder. Finished models go in `Bathhouse/Structures/` as
`.glb` files ([structures](../docs/structures.md)).
